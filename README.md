# 肉鸽游戏 Demo

一个用 Python + Pygame 制作的肉鸽（Roguelike）风格游戏 demo，目前实现了：
- 主菜单（进入游戏 / 读档 / 操作设置 / 退出游戏）
- 无限地图（永不遇到边界）
- 玩家长方形 + WASD 移动（默认）
- 相机跟随
- 操作键位自定义
- JSON 存档 / 读档

## 运行

```bash
pip install pygame
python main.py
```

## 文件结构

| 文件 | 作用 |
|------|------|
| `main.py` | 程序入口 |
| `game.py` | 游戏主控制（状态机） |
| `settings.py` | 全局配置常量 |
| `menu.py` | 主菜单 |
| `game_scene.py` | 游戏场景（无限地图、玩家、相机） |
| `settings_scene.py` | 操作设置界面 |
| `save_load.py` | 存档 / 读档 |

## 操作

| 按键 | 作用 |
|------|------|
| W/A/S/D | 移动（默认） |
| ESC | 返回菜单 |
| F5 | 快速存档（游戏中） |
| 1/2/3/4 | 在设置界面分别重新绑定 上/下/左/右 |
